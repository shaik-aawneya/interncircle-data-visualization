# Data Visualization with Matplotlib & Seaborn

## Project Overview
This project explores the Seaborn Tips dataset using Python visualization libraries. It focuses on identifying patterns, comparing distributions, and understanding relationships between restaurant bills, tips, and table sizes.

## Dataset
- **Dataset:** Seaborn Tips Dataset
- **Records:** 244
- **Features:** 7
- **Missing values:** None

## Research Questions
1. How are restaurant bills distributed among customers?
2. How do tip amounts vary across different days?
3. Is there a relationship between the total bill and tip amount?
4. Which numerical variables have the strongest correlations?

## Visualizations

The project includes four visualizations:

1. **Histogram:** Distribution of restaurant bills.
2. **Box Plot:** Comparison of tip amounts across different days.
3. **Scatter Plot:** Relationship between total bill and tip amount.
4. **Correlation Heatmap:** Relationships between numerical variables.

## Key Findings
- Most restaurant bills are concentrated between $10 and $25.
- Friday has the highest median tip among the four recorded days.
- Total bill and tip amount have a positive correlation of approximately 0.68.
- Total bill and table size have a positive correlation of approximately 0.60.
